### Question 1

**Question:** What is the primary function of a git stash command?

- **A.** Delete local commits
- **B.** Save current changes
- **C.** List all branches
- **D.** Merge remote branch

**Correct Answer:** B

**Question Type:** Single Choice

**Explanation:** git stash temporarily saves uncommitted changes so the working directory can be cleaned without committing them.

### Question 4

**Question:** What does a Binary Search Tree (BST) property require?

- **A.** Left < Node < Right
- **B.** Left > Node > Right
- **C.** Node = Left + Right
- **D.** Node < Left < Right

**Correct Answer:** A

**Question Type:** Single Choice

**Explanation:** A BST requires values in the left subtree to be less than the node and values in the right subtree to be greater, under the standard BST property.

### Question 17
